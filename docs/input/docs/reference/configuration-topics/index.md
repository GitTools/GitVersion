Start with [Configure GitVersion][configure-gitversion] for file names, discovery, and inspecting the effective configuration.

## Choose a topic

- [Workflow defaults][workflow-defaults]: GitFlow/v1, GitHubFlow/v1, and experimental TrunkBased/preview1.
- [Version calculation][version-calculation]: sources, increments, and history filters.
- [Branch configuration][branch-configuration]: matching, inheritance, and merge behavior.
- [Output and formatting][output-and-formatting]: assembly versions, custom formats, and build numbers.

The [complete configuration reference][complete-configuration-reference] remains the authoritative settings catalog. Its existing URLs and anchors are preserved.
